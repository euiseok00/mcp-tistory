# 티스토리 임시저장 내부 API 조사

조사일: 2026-10-29. 방법: 글쓰기 화면(`/manage/newpost/`)에서 임시저장 클릭 → 페이지 XHR 로깅으로 요청·응답 캡처.
비공식 API이므로 언제든 바뀔 수 있다.

## 엔드포인트

| 용도 | 요청 |
|---|---|
| 신규 임시저장 | `POST https://{blog}.tistory.com/manage/drafts` |
| 기존 임시글 갱신 | `POST https://{blog}.tistory.com/manage/drafts/{sequence}` |

- MVP는 매 호출마다 신규 임시저장만 사용한다.
- 에디터는 별도로 `POST /manage/autosave`를 주기 호출한다 (MVP에선 사용 안 함).

## 요청
- 헤더: `Content-Type: application/json`, `Accept: application/json, text/plain, */*`
- CSRF 토큰 헤더 없음. 인증은 로그인 쿠키만 사용.
- 본문:
  ```json
  {
    "title": "[MCP 테스트] 임시저장 캡처용",
    "content": "<p data-ke-size=\"size16\">본문 테스트 문장입니다.</p>",
    "tags": "",
    "categoryId": 0,
    "totalWritingTimeMs": 108989
  }
  ```
  - `content`는 HTML 문자열. 마크다운 모드로 작성해도 서버에는 HTML로 전송된다 (변환은 브라우저에서 수행).
  - `totalWritingTimeMs`는 `0`으로 보내도 신규 생성 성공.

## 응답
```json
{ "success": true, "total": 3, "draft": { "sequence": 13 } }
```
- `draft.sequence` → `draftId`로 사용
- `total` → 현재 임시저장 글 개수

## 직접 호출 검증
- 에디터 UI를 거치지 않고 페이지 컨텍스트에서 `fetch('/manage/drafts', {method:'POST', ...})`로 신규 생성 → 임시저장함에 `[MCP 테스트] 직접호출` 글 생성 확인. 서버(Docker 컨테이너)에서 브라우저 Cookie 헤더 + `Origin`/`Referer`를 붙여 보낸 요청도 성공 (2026-10-29 E2E). `Origin`/`Referer` 없이도 되는지는 미확인.
- 쿠키 없이(`credentials: 'omit'`) 보낸 요청은 임시글이 생성되지 않음.
- 서버(curl)에서 무효 쿠키로 보낸 요청: `302` → `https://www.tistory.com/auth/login?...`. `SESSION_EXPIRED` 판정 기준으로 사용.

## 마크다운 모드 저장 HTML (티스토리 에디터 출력)
입력 마크다운: 제목(`##`), 목록, 표, 코드블록(`javascript`), 인용, 링크, 굵게, 기울임.

```html
<h2>소제목</h2>
<ul>
<li>목록1</li>
<li>목록2</li>
</ul>
<table>
<thead>
<tr>
<th>A</th>
<th>B</th>
</tr>
</thead>
<tbody><tr>
<td>1</td>
<td>2</td>
</tr>
</tbody></table>
<pre><code class="language-javascript">const a = 1;
</code></pre>
<blockquote data-ke-style="style1"><p data-ke-size="size16"><span style="font-family: 'Noto Serif KR', ...">인용문</span></p></blockquote>
<p><a href="https://example.com">링크</a> <strong>굵게</strong> <em>기울임</em></p>
```
(인용 `span`의 `style` 뒷부분은 조사 도구 출력 제한으로 일부 생략)

**결론:** 표준 마크다운 → HTML 변환 결과(`marked`/`markdown-it` 계열)와 거의 같다.
- 코드블록: `<pre><code class="language-{lang}">`
- 표: 속성 없는 기본 `<table>`
- 인용: `data-ke-style="style1"` + 내부 `<p data-ke-size="size16">` (티스토리 전용 장식)

따라서 서버는 일반 마크다운 라이브러리로 변환해도 된다. 인용 장식은 선택 사항.

## 미확인
- 인증 쿠키 이름 (현재는 브라우저 Cookie 헤더 전체를 주입하므로 몰라도 동작)
- 임의 HTML(`<script>` 포함) 전송 시 서버 측 필터링 여부 → `[MCP 테스트] 직접호출` 글(`<script>` 포함)을 에디터에서 열어 확인 가능. 서버 필터링과 무관하게 우리 쪽에서 제거한다.
- 신규 생성 응답이 갱신 응답과 같은 형식인지 (같을 것으로 추정)
- 임시저장 개수 상한
